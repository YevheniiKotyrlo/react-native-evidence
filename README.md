# react-native evidence

Screenshots, screen recordings, charts and device readings behind the pull requests and issues I post evidence on in [react/react-native](https://github.com/react/react-native). Each pair comes from one device — a simulator, an emulator or a phone — in one session and differs only in whether the change is applied: for a pull request, `before` is `main` at the commit its comment names, or the head of the pull request it is stacked on, and `after` adds the pull request; for an issue, `before` is the release it names and `after` adds the fix it proposes. A recording plays both builds side by side in one GIF, and [`captures/`](captures) holds its two source videos with every frame the device captured. A chart plots a device measurement of both builds, and its comment names the device and how the measurement was taken. A page holds a pull request's or an issue's builds, steps and readings, with the tool output beside it.

[`tools/`](tools) holds the scripts the steps run: [`count-distinct-frames.sh`](tools/count-distinct-frames.sh) counts the different images a screen region shows across screenshots, [`hold-press.sh`](tools/hold-press.sh) holds a finger past the long-press delay and reads the screen, [`keyboard-paste.sh`](tools/keyboard-paste.sh) copies a field with Ctrl+A and Ctrl+C and pastes it into other fields with Ctrl+V, [`mouse-click.mjs`](tools/mouse-click.mjs) clicks a point with a virtual mouse, and [`right-click-caret.sh`](tools/right-click-caret.sh) reads where a right-click leaves a field's caret.
