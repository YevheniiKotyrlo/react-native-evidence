# react-native evidence

Screenshots, screen recordings and charts behind my pull requests and issues in [react/react-native](https://github.com/react/react-native). Each pair comes from one device — a simulator, an emulator or a phone — in one session and differs only in whether the change is applied: for a pull request, `before` is `main` at the commit its comment names and `after` adds the pull request; for an issue, `before` is the release it names and `after` adds the fix it proposes. A chart plots a device measurement of both builds, and its comment names the device and how the measurement was taken.
